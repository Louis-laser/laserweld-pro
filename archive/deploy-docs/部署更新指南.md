# LaserWeld Pro - 部署更新指南

## 更新流程概览

```
修改代码/数据 → Git提交 → Push到GitHub → EdgeOne自动部署
                              → Vercel手动部署（可选）
```

---

## 核心命令（一条龙）

**每次修改完代码/数据后，在项目目录执行：**

```bash
cd ~/.openclaw/workspace/projects/激光焊接参数查询工具

# 1. Git提交
git add .
git commit -m "更新说明"

# 2. 推送到GitHub（EdgeOne会自动检测并部署）
git push

# 3. 可选：同步部署到Vercel（海外访问用）
npx vercel --prod --yes
```

---

## 各类更新的操作清单

### 1. 修改焊接参数（数据更新）

**场景：** 改 `data/params.js` 里的材料参数、焊接参数

| 动作 | 是否需要 | 说明 |
|------|----------|------|
| 修改数据文件 | ✅ 手动 | 编辑 `data/params.js` |
| Git commit + push | ✅ | 触发 EdgeOne 自动部署 |
| 清浏览器缓存 | ⚠️ 推荐 | Ctrl+F5 或清除缓存 |

> **注意：** 参数数据结构有约定格式，改完后建议打开页面验证是否正常加载

### 2. 修改界面/功能（代码更新）

**场景：** 改 `index.html`、`sw.js`、`manifest.json` 等

| 动作 | 是否需要 | 说明 |
|------|----------|------|
| 修改代码 | ✅ 手动 | |
| Git commit + push | ✅ | 触发 EdgeOne 自动部署 |
| 同步 Verce l | ⚠️ 可选 | 海外访问用 |
| 清浏览器缓存 | ✅ 必须 | 否则可能加载旧版本 |

### 3. 更换收款二维码

**场景：** 替换 `assets/qr-wechat.png`、`assets/qr-alipay.png`

| 动作 | 是否需要 | 说明 |
|------|----------|------|
| 替换图片文件 | ✅ 手动 | 保持文件名不变 |
| Git commit + push | ✅ | |
| 无需改代码 | ✅ | HTML里写死的图片路径 |

### 4. 纯数据修正（不涉及代码）

**场景：** 只是修改某个焊接参数值

```bash
# 编辑数据后快速提交
cd ~/.openclaw/workspace/projects/激光焊接参数查询工具
git add data/
git commit -m "fix: 修正XX材料焊接参数"
git push
```

## 部署平台管理

### EdgeOne Pages（国内主力）

- **控制台：** https://console.cloud.tencent.com/edgeone/pages
- **部署方式：** 推送到 GitHub 自动触发部署
- **手动部署：** `~/.local/bin/edgeone pages deploy`
- **项目名：** `laserweld-pro`
- **自动部署：** EdgeOne 已关联 GitHub 仓库，`git push` 后自动构建上线（约1分钟）

### Vercel（海外备用）

- **控制台：** https://vercel.com/luxiangzhi33-4259s-projects/laserweld-pro
- **部署方式：** `npx vercel --prod --yes`
- **回滚：** `npx vercel rollback`

## 常见问题

### Q: 改了数据，GitHub 已 push，EdgeOne 没更新？
EdgeOne 自动构建需要 1-2 分钟，等待后刷新页面。如果还没更新，去 EdgeOne 控制台看构建日志。

### Q: 改错了文件怎么回滚？
```bash
git revert HEAD    # 撤销最近一次提交
git push           # 推上去就自动复原
```
