# banners/ — 顶部轮播广告图片

## 使用方法

将你的激光器全家福图片放入此文件夹，命名为：

```
banners/
├── banner-1.jpg    ← 轮播图 ①
├── banner-2.jpg    ← 轮播图 ②
├── banner-3.jpg    ← 轮播图 ③
└── README.md       ← 本文件
```

## 图片规格

| 参数 | 要求 |
|------|------|
| 尺寸 | **800×350px**（推荐），会自动缩放 |
| 宽高比 | 约 **16:7** |
| 格式 | JPG / PNG / WebP |
| 风格 | 深色背景（与UI主题一致效果最佳） |
| 主题 | 激光器产品、焊接应用场景、技术方案 |

## 注意事项

- 替换图片后，**刷新浏览器**即可看到新图（无需重启）
- 如浏览器仍显示旧图，请 `Cmd+Shift+R` 强制刷新
- 文件名保持不变，只替换图片内容
- 建议所有图片保持相同尺寸，避免切换时视觉跳动
- 原占位图由程序生成，替换为自己图片后不会丢失
