## 3. 交互组件

### 3.1 材料选择网格

```
┌──────────┬──────────┐
│ 🔩 不锈钢  │ 🛡️ 碳钢  │  ← 选中态：蓝色边框+浅蓝背景
├──────────┼──────────┤
│  🫨 镀锌板  │ 💎 钛合金 │
├──────────┼──────────┤
│ 🔵 铝     │ 🟠 铜    │  ← 带子菜单箭头
│ 1~7系    │ 纯铜+合金 │
└──────────┴──────────┘
```

- **同种材料模式**：选一个材料
- **异种材料模式**：选材料A、材料B（紫色边框）
- **铝/铜**：点击弹出子材料选择 Modal
- **选中态**：蓝色边框(A) / 紫色边框(B) + 对应角标

### 3.2 子材料 Modal

```
┌──────────────────┐
│   选择铝合金系列    │
├────────┬─────────┤
│ 🔵 1系  │ 🔵 2系   │
│ 纯铝    │ 铝铜合金  │
├────────┼─────────┤
│ 🔵 3系  │ 🔵 5系   │
│ ...    │ ...     │
└────────┴─────────┘
        [关闭]
```

- 半透明蒙版 + 浮动居中卡片
- 2列网格布局
- 选中后自动关闭 Modal 并刷新结果

### 3.3 Banner 轮播

```
┌──────────────────────────────┐
│         🔦 激光器全家福         │  ← 3张图自动切换
│        可替换此图片              │
└──────────────────────────────┘
       ○ ○ ○（圆点导航）
```

- 自动播放：每4秒切换
- 用户点击圆点：跳转到对应图片 + 计时器重置
- 占位符：设计为可替换 `<img>` 标签（由用户上传更新）

### 3.4 厚度滑块

```
      ───────●───────   ← 滑块条
         1.5 mm
  ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐
  │0.5│ │1.0│ │1.5│ │3.0│ │5.0│  ← 预设按钮
  └─┘ └─┘ └─┘ └─┘ └─┘
```

- 滑块 + 数字显示 + 预设值快捷按钮
- 拖动时实时更新结果

## 4. 动效设计

| 元素 | 效果 |
|------|------|
| 卡片加载 | `fadeIn 0.3s ease` 渐入 |
| 材料卡片悬浮 | 边框变色 + 上移1px |
| 文章卡片悬浮 | 边框变色 + 右移2px |
| 订阅按钮悬浮 | 放大1.02倍 |
| 订阅按钮点击 | 缩小0.98倍 |
| 轮播切换 | `opacity 0.8s ease` 淡入淡出 |
| 圆点切换 | 宽度从6px→18px 动画 |

## 5. 技术栈

- **纯前端**：无框架依赖，单 html 文件
- **CSS**：自定义属性（`:root`）+ Flexbox + Grid
- **JavaScript**：原生 ES6+
- **字体**：系统字体栈（macOS/iOS/Android）
- **兼容**：移动端适配，`max-width: 500px`，无外部依赖
