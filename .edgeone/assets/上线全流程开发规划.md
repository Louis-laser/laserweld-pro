### 5.1 localStorage 持久化（1天）

```javascript
// 订阅状态存储
const SUB_STATUS_KEY = 'laserweld_subscription';

function getSubscription() {
  return JSON.parse(localStorage.getItem(SUB_STATUS_KEY)) || null;
}

function setSubscription(data) {
  localStorage.setItem(SUB_STATUS_KEY, JSON.stringify({
    ...data,
    subscribedAt: Date.now(),
    deviceId: generateDeviceId(),
  }));
}

function clearSubscription() {
  localStorage.removeItem(SUB_STATUS_KEY);
}
```

**功能：**
- 刷新页面后保持订阅状态
- 同设备打开不再显示门控
- 提供清除入口（管理后台/联系我们）

### 5.2 支付流程状态机（1天）

```
IDLE → [点击订阅] → PAYMENT_SELECT(选方式)
     → [展示QR码] → WAITING_PAYMENT
     → [用户点击"我已支付"] → VERIFYING
     → VERIFIED → [写入localStorage] → UNLOCKED
     
失败路径:
WAITING_PAYMENT → [取消] → IDLE
VERIFYING → [支付失败提示] → PAYMENT_SELECT
```

**UI变化：**
- 支付中：按钮置灰 + 加载 Spin
- 支付成功：绿色 ✅ 提示 + 自动关闭门控
- 支付失败：红色提示 + 重试按钮
