# 02 · 更新技术文章

**说明：** 技术文章内容全部来源于 IMA 个人知识库笔记。修改需要：
1. 先在 IMA 中更新对应笔记
2. 然后通过 IMA API 读取新内容
3. 更新前端 `index.html` 中的 `ARTICLE_FULL` 常量

---

## 数据格式

### `data/articles.js` - 文章元数据

```javascript
var ARTICLES_DATA = [
  {
    id: 'art6',              // 唯一ID，按 art1~artN 递增
    title: '文章标题',         // 标题
    desc: '文章简介，30-50字', // 卡片描述
    badge: 'IMA笔记',         // 标签文字
    icon: '📘',               // 卡片图标 emoji
    source: 'ima'             // 固定为 'ima'，表示来源 IMA 笔记
  },
  // ...
];
```

### `index.html` - 文章正文（`ARTICLE_FULL` 常量）

位于 `index.html` 中 `<script>` 之后，`// 材料定义` 之前。

```javascript
var ARTICLE_FULL = {
  art1: `# 文章标题\n\n文章正文内容（Markdown 格式）`,
  // ...
};
```

---

## 更新流程

### 第1步：在 IMA 中编辑笔记内容
- 打开 IMA 笔记
- 找到对应文章的笔记
- 编辑正文内容（Markdown 格式）

### 第2步：通过 IMA API 读取最新内容

```bash
cd ~/.openclaw/workspace/skills/ima-skill
SKILL_DIR="$(pwd)"
OPTS=$(printf '{"clientId":"%s","apiKey":"%s"}' "$IMA_OPENAPI_CLIENTID" "$IMA_OPENAPI_APIKEY")

# 读取笔记内容
node "$SKILL_DIR/ima_api.cjs" "openapi/note/v1/get_doc_content" \
  '{"note_id":"7465234486818134","target_content_format":0}' "$OPTS"

# 注意：target_content_format=0 返回纯文本，=1 返回 Markdown（JSON 内嵌）
```

### 第3步：更新 `index.html` 中的 `ARTICLE_FULL` 常量
- 将读取到的新内容替换到对应 `artN` 的模板字符串中
- 注意模板字符串内不能包含反引号（\`），如需代码块请改用缩进
- 注意模板字符串内 `\${` 需转义为 `\${`

### 第4步：本地测试

```bash
cd ~/.openclaw/workspace/projects/激光焊接参数查询工具
python3 -m http.server 8080
# 浏览器打开 → 点击文章卡片 → 应弹出阅读弹窗
```

### 第5步：提交部署

```bash
git add data/articles.js index.html
git commit -m "chore: 更新技术文章《XXX》内容（来源 IMA 笔记）"
git push
```
