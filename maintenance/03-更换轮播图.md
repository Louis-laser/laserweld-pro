# 03 · 更换轮播图

**目标文件夹：** `banners/`

## 文件命名

| 文件名 | 展示顺序 | 建议尺寸 |
|--------|---------|---------|
| `banner-1.jpg` | 第1张（默认显示） | 500×280px |
| `banner-2.jpg` | 第2张 | 500×280px |
| `banner-3.jpg` | 第3张 | 500×280px |

## 操作步骤

```bash
# 1. 准备图片（推荐 500×280px，JPG 格式）
# 2. 替换文件（保持文件名不变，无需改代码）
cp /path/to/new-image1.jpg ~/.openclaw/workspace/projects/激光焊接参数查询工具/banners/banner-1.jpg
cp /path/to/new-image2.jpg ~/.openclaw/workspace/projects/激光焊接参数查询工具/banners/banner-2.jpg
cp /path/to/new-image3.jpg ~/.openclaw/workspace/projects/激光焊接参数查询工具/banners/banner-3.jpg

# 3. 提交部署
cd ~/.openclaw/workspace/projects/激光焊接参数查询工具
git add banners/
git commit -m "feat: 更新Banner轮播图"
git push
```

## 注意事项

- 文件名**必须保持一致**，HTML 里写死了 `banner-1.jpg` / `banner-2.jpg` / `banner-3.jpg`
- 如需增加/减少张数，需修改 `index.html` 中的轮播数据数组
- 建议所有 Banner 使用深色背景，与整体暗色主题协调
