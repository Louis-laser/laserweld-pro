# 05 · 更新订阅定价

**目标文件：** `index.html` （搜索 `planOnce` / `planMonthly` / `subDesc` 近处）

## 当前定价方案

| 方案 | JS变量 | 价格 | 有效期 |
|------|--------|------|--------|
| 单次解锁 | `plan 'once'` | ¥20 | 当前查询参数 |
| 月度订阅 | `plan 'monthly'` | ¥6/月 | 30天 |

## 如何修改价格

### 修改展示价格

在 `index.html` 中搜索以下行并修改数字：

```html
<!-- 定价标签（约1179行）-->
<div style="font-size:10px;color:var(--text2);margin-bottom:8px;">🔑 单次¥20 · 📅 月度¥6/月</div>

<!-- 单次方案价格（约1190行）-->
<div style="font-size:18px;font-weight:700;color:var(--accent);">¥20</div>

<!-- 月度方案价格（约1196行）-->
<div style="font-size:18px;font-weight:700;color:var(--green);">¥6</div>
```

### 修改订阅有效期

```javascript
// index.html 中约 2050-2060 行
// 月度订阅30天有效期
var subAge = Date.now() - sub.monthlyAt;
if (subAge > 30 * 24 * 60 * 60 * 1000) {
    // 已过期
}
```

### 修改订阅触发条件

搜索 `shouldLockBySubscription()` 函数（约 2190 行附近），4条条件：

| 条件 | 代码 |
|------|------|
| ≤0.3mm 薄板 | `thickness <= 0.3` |
| 钛金属 | `mat === 'titanium'` |
| 异种材料 | `m1 !== m2` |
| 气密性要求 | 关键词匹配 |

## 高级：新增订阅方案

如需增加新方案（如年费），需修改：

1. 支付面板 HTML（新增一个 `plan-opt` 块）
2. `selectPlan()` 函数（识别新方案）
3. `confirmPay()` / `setSubscription()`（存储新方案类型）
4. `getSubscription()` 校验逻辑（过期判定逻辑）
