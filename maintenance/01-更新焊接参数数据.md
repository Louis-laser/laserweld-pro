# 01 · 更新焊接参数数据

**目标文件：** `data/params.js`

## 📊 推荐方法：编辑 Excel 模板（一键转换）

这是推荐的更新方式 —— 打开 Excel 改数据，跑脚本自动更新。

### 操作流程

```bash
# 1. 打开 Excel 模板编辑
cd ~/.openclaw/workspace/projects/激光焊接参数查询工具
open 焊接工艺参数模板.xlsx

# 2. 在 "工艺参数数据" 表中修改数据
#    - 同种材料：材料1 = 材料2
#    - 异种材料：材料1 ≠ 材料2
#    - 第二行有填写说明，鼠标悬停可查看

# 3. 保存 Excel，运行转换脚本
python3 scripts/xlsx2params.py

# 4. 验证生成的 params.js
node --check data/params.js

# 5. 提交部署
git add data/params.js 焊接工艺参数模板.xlsx
git commit -m "data: 更新焊接参数"
git push
```

### 转换规则

| Excel 列 | params.js 字段 | 说明 |
|----------|---------------|------|
| 材料1 / 材料2 | 材料 key | `材料1 == 材料2` → 同种数据；`≠` → 异种数据 |
| 焊接模式 | cw / pulse | `cw` 连续 / `pulse` 脉冲 |
| 板厚(mm) | 厚度 key | 浮点数，精确到 0.1mm |
| 功率(W) | `power` | 自动生成 `[min, max]` 范围 |
| 速度(mm/s) | `speed` | 同上 |
| 焦点(mm) | `focus` | 同上 |
| 气流量(L/min) | `gas_flow` | 同上 |
| 脉冲频率/占空比/峰值功率 | `freq` / `duty` / `ppk` | 仅脉冲模式有效，生成 `[值, 值]` |

### 首次使用：回填全量数据

如果模板数据不全，可以先从现有的 params.js 反向生成完整模板：

```bash
python3 scripts/xlsx2params.py --backfill
# 生成 焊接工艺参数模板_回填.xlsx（覆盖所有厚度）
```

### 并行模式

脚本是 **合并模式** 运行的：
- Excel 中有对应材料+厚度+模式的行 → 用 Excel 数据覆盖
- 其他厚度保持不变
- Excel 有现有数据中没有的新厚度 → 新增

所以你可以只改 3-5 行你关心的数据，不必一次填满。

## 🔧 备用方法：手动编辑 params.js

不推荐，但需要的场景：
- 需要脉冲参数的 `[min, max]` 范围（Excel 只支持单值）
- 临时热修复，不方便打开 Excel

### 数据格式

```javascript
var PARAMS_DATA = {
    ss304: {         // ← 材料ID（必须唯一）
      cw: {           // ← 焊接模式: cw(连续) / pulse(脉冲)
        0.5: {        // ← 厚度 (mm)，自动找最近匹配
          power:     [500, 800],     // 激光功率 W [最小值, 最大值]
          speed:     [30, 50],       // 焊接速度 mm/s
          focus:     [0, 0],         // 焦平面位置 mm（负=焦点入工件内）
          gas_flow:  [12, 15],       // 保护气流量 L/min
          // 以下仅脉冲模式需要:
          freq:      [25, 40],       // 频率 Hz
          duty:      [40, 60],       // 占空比 %
          ppk:       [1500, 2500],   // 峰值功率 W
        },
        // ...
      },
      // ...
    },
    // ...
};
```

### 材料ID对照表

| 显示名称 | data/params.js ID | 说明 |
|---------|-------------------|------|
| 不锈钢(304) | `ss304` | — |
| 碳钢 | `carbon` | — |
| 镀锌板 | `galvanized` | — |
| 铝 | `aluminum` | — |
| 铜 | `copper` | — |
| 钛合金 | `titanium` | — |
| 黄铜 | `brass` | 铜子材料，独立数据 |

### 厚度段说明

代码用 `findClosestThicknessKey()` 自动找最近厚度，预定义厚度列：

```
0.1, 0.2, 0.3, 0.5, 0.8, 1.0, 1.2, 1.5, 2.0, 2.5, 3.0, 4.0, 5.0, 6.0, 8.0, 10.0, 12.0
```

如需增加新厚度段，需在 JS 的 `ALL_THICKNESS_KEYS` 数组中注册。

### 手动操作步骤

```bash
# EdgeOne 自动部署（约1分钟）
```

## 注意事项

- **单位统一**：功率 W、速度 mm/s、焦点 mm、气流量 L/min、频率 Hz、占空比 %
- **脉冲模式**：如果某厚度没有脉冲数据，程序会降级用 CW 连续模式，建议补齐
- **子材料修正**：铝系/铜系子材料在 `data/sub-factors.js` 中定义，修改后影响所有厚度
- **接头修正**：在 `index.html` 的 `JOINT_FACTOR` 常量中，全局生效
- **脉冲参数限制**：Excel 模板只支持单值（非范围），如果你需要 `[min, max]` 范围，手动编辑 params.js
