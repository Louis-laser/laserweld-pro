# 07 · 更新部署配置

**涉及文件：** 域名/DNS/PWA/缓存策略

## PWA配置修改

| 文件 | 修改内容 |
|------|---------|
| `manifest.json` | 应用名称、图标路径、主题色、显示模式 |
| `sw.js` | 缓存策略、离线资源列表、版本号 |
| `favicon.svg` | 浏览器标签页图标 |

### 更新 Service Worker 版本

搜索 `sw.js` 开头的版本号：

```javascript
const CACHE_VERSION = 'laserweld-v1';
```

改版本号会触发旧缓存失效。

## 缓存策略

当前使用 Workbox 风格的策略（在 `sw.js` 中）：

| 资源类型 | 策略 | 缓存时长 |
|---------|------|---------|
| HTML | Network First | 不缓存 |
| CSS/JS | Cache First（内联无需额外处理） | — |
| 图片 | Cache First | 7天 |
| 字体 | Cache First | 30天 |

## 自定义域名

如需绑定自定义域名：

```html
<!-- 在 index.html 的 <head> 中更新 OG 图片的域名 -->
<meta property="og:image" content="https://your-custom-domain.com/og-image.png">
```

部署平台操作：

| 平台 | 操作路径 |
|------|---------|
| EdgeOne | 控制台 → 域名管理 → 添加自定义域名 |
| Vercel | 项目设置 → Domains → 添加域名 |

## 搜索引擎收录

确保 `<head>` 中有以下标签：

```html
<title>LaserWeld Pro · 激光焊接参数查询工具</title>
<meta name="description" content="免费激光焊接参数查询工具...">
<meta name="keywords" content="激光焊接,焊接参数,...">
```

如需屏蔽搜索引擎索引（开发环境）：`<meta name="robots" content="noindex">`
