# 04 · 更换收款二维码

**目标文件夹：** `assets/`

## 文件命名

| 文件名 | 用途 | 建议尺寸 |
|--------|------|---------|
| `qr-wechat.png` | 微信收款码 | 120×120px |
| `qr-alipay.png` | 支付宝收款码 | 120×120px |

## 操作步骤

```bash
# 1. 准备好收款码截图（PNG格式）
# 2. 替换文件
cp /path/to/wechat-qr.png ~/.openclaw/workspace/projects/激光焊接参数查询工具/assets/qr-wechat.png
cp /path/to/alipay-qr.png ~/.openclaw/workspace/projects/激光焊接参数查询工具/assets/qr-alipay.png

# 3. 提交部署
cd ~/.openclaw/workspace/projects/激光焊接参数查询工具
git add assets/
git commit -m "fix: 替换收款二维码"
git push
```

## 注意事项

- **文件名必须保持不变**，HTML 里写死了路径
- HTML 引用的是 `assets/qr-wechat.png` 和 `assets/qr-alipay.png`
- ⚠️ 收款码涉及真实资金，替换后务必自己走一遍支付流程确认
- 如果 QR 码更新后发现不显示，检查文件名大小写
