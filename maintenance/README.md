# LaserWeld Pro · 维护手册

> 所有更新操作的统一入口。按需选择对应指南。

## 📂 文件结构

```
maintenance/
├── README.md               ← 本文件，维护入口
├── 01-更新焊接参数数据.md    ← params.js 增/改/删
├── 02-更新技术文章.md        ← articles.js 增/改/删

├── 04-更换收款二维码.md       ← assets/qr-* 替换

```

## 🔄 常用更新速查

| 想做什么 | 去哪个文件 | 耗时 |
|---------|-----------|------|
| 改某材料某个厚度的参数 | `01-更新焊接参数数据.md` | 3分钟 |
| 新增一篇技术文章 | `02-更新技术文章.md` | 5分钟 |
| 换一张轮播图 | `03-更换轮播图.md` | 2分钟 |
| 换收款二维码 | `04-更换收款二维码.md` | 2分钟 |
| 改价格 | `05-更新订阅定价.md` | 5分钟 |
| 改页面颜色 | `06-更新UI样式.md` | 5分钟 |
| 修改域名/部署 | `07-更新部署配置.md` 或 `../软件更新及上线操作指南.md` | 10分钟 |

## ⚠️ 核心原则

1. **数据先审后改** — 焊接参数涉及工艺安全，改完建议页面测试确认
2. **改完记得部署** — 所有更新都要 `git add + commit + push` 才能上线
3. **部署后清缓存** — 用户浏览器可能加载旧版本，Ctrl+F5 或告诉用户刷新
4. **定价/支付信息谨慎** — 涉及真实收费，改完务必自测一次支付流程
