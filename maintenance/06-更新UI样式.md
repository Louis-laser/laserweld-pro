# 06 · 更新UI样式

**目标文件：** `index.html`

## 色彩体系（:root CSS变量）

所有颜色通过 CSS 自定义属性管理，搜索 `:root` 段：

```css
:root {
  --bg: #0d1117;         /* 页面背景 */
  --surface: #161b22;    /* 卡片底色 */
  --surface2: #1c2333;   /* 卡片底色2 */
  --border: #30363d;     /* 边框 */
  --text: #e6edf3;       /* 主文字 */
  --text2: #8b949e;      /* 次级文字 */
  --accent: #58a6ff;     /* 品牌蓝色 */
  --accent2: #1f6feb;    /* 品牌蓝深色 */
  --green: #3fb950;      /* 易焊/成功 */
  --yellow: #d29922;     /* 可焊/警告 */
  --orange: #f0883e;     /* 困难/订阅 */
  --red: #f85149;        /* 不推荐/错误 */
  --purple: #a371f7;     /* 异种材料/订阅标识 */
}
```

改一个变量影响全站同色元素。

## 焊接可行性颜色（独立于主题）

搜索 `.w-card-green` / `.w-card-yellow` / `.w-card-orange` / `.w-card-red` 类。

每个类包含 `background` + `border-color` + 对应语义颜色。

## 布局修改

- 最大宽度：`.container` 的 `max-width: 500px`
- 响应式：基于 `max-width: 500px` 居中设计
- 如需增加步骤：在 HTML 中插入新的 Step div，参照现有 Step 结构

## 动效

| 位置 | 效果 |
|------|------|
| `.fade-in` | `opacity 0.3s ease` — 卡片加载渐入 |
| `.card:hover` | 缩放/位移动画 — 悬浮反馈 |
| 轮播 | `opacity 0.8s ease` — 图片切换 |
| 订阅按钮 | `scale(1.02)`/`scale(0.98)` — 按击反馈 |

## 更换品牌图标

- **Header图标**：`<span class="brand-icon">⚡</span>` — 替换 emoji 即可
- **favicon**：`assets/favicon.svg` — 替换 SVG 文件
- **PWA图标**：`assets/icon-192.png` + `assets/icon-512.png` — 替换 PNG 文件
