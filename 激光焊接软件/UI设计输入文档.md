## 1. 设计原则

### 1.1 核心设计理念

```
工具属性 > 装饰属性     → 每一像素都为提升效率服务
信息层级 > 信息堆砌     → 核心参数一眼可见，次要参数可查
移动优先 > 桌面适配     → 现场操作场景决定手机端是第一屏幕
零学习 > 有教程         → 打开即用，不依赖帮助文档
```

### 1.2 设计优先级排序

| 优先级 | 原则 | 解释 |
|--------|------|------|
| P0 | 信息可读性 | 参数必须清晰、准确、无歧义 |
| P0 | 操作效率 | 从打开页面到查到参数 ≤ 3次点击 |
| P1 | 视觉层次 | 核心参数(功率/速度)优先展示，次要参数可折叠 |
| P1 | 移动端适配 | 手机小屏不溢出、不模糊、不误触 |
| P2 | 一致性 | 同一组件在不同位置保持相同样式和行为 |
| P2 | 美观度 | 干净、专业，不过度设计 |

## 2. 用户场景与使用行为

### 2.1 三类用户的使用场景

| 用户类型 | 使用场景 | 设备 | 核心动作 | 每次用时 |
|----------|----------|------|----------|----------|
| 工艺工程师 | 调试新焊接参数时查询参考值 | 电脑(主) + 手机(辅) | 输入材料+厚度 → 比较不同参数 → 记录 | 2~5分钟 |
| 焊接操作员 | 现场换料换厚度时急查参数 | 手机(主) | 快速搜索 → 看一眼功率/速度 → 调机 | 10~30秒 |
| 工艺研发/管培生 | 学习不同材料的焊接特性 | 电脑 | 浏览 → 对比 → 理解参数规律 | 5~15分钟 |

### 2.2 关键行为模式

**高频操作路径（现场操作员）：**
```
打开页面 → 输入材料名 → [调整厚度] → 看结果 → 关页面
                                           ↕
                                        [调整接头类型]
```

**低频操作路径（工程师）：**
```
打开页面 → 输入材料 → 翻阅多页结果 → 对比不同厚度的参数 → [导出/记下] → 关页面
                                                   ↕
                                               [调整其他条件]
```

### 2.3 设计底线

- 核心参数（功率、速度）**不能在手机屏幕上换行或被截断**
- 搜索输入框必须足够大，防误触（手指≥44px）
- 结果加载必须有明确反馈（骨架屏或加载指示器）

## 3. 信息架构

### 3.1 页面结构映射

```
首页（唯一页面）
│
├── 头部区域（粘性）
│   ├── Logo + 标题
│   └── 副标题/提示文字
│
├── 搜索面板
│   ├── 材料输入（主搜索框，支持自动补全）
│   ├── 接头类型下拉（懒加载自API）
│   ├── 厚度范围（起点/终点输入）
│   ├── ⏳ 质量等级筛选（P2 待实现）
│   ├── ⏳ 功率范围筛选（P2 待实现）
│   └── 查询按钮 + 清除按钮
│
├── 搜索结果区
│   ├── 统计条（总条数 + 当前页）
│   ├── 结果卡片列表
│   │   └── 每个卡片包含：
│   │       ├── 材料对标题区
│   │       ├── 核心参数区（功率/速度/厚度 — 大字突出）
│   │       ├── 辅助参数区（离焦/保护气/气流量/工装 — 可折叠）
│   │       ├── 质量等级标识（色块 + 文字）
│   │       └── 备注区
│   └── 空结果状态（推荐搜索词）
│
├── ⏳ 快捷导航（P2）
│   └── 热门材料标签 / 最近搜索
│
└── 页脚
    └── 版本号 + 数据声明
```

### 3.2 状态视图

| 状态 | 页面表现 | 触发条件 |
|------|----------|----------|
| 初始态 | 显示欢迎提示 + 热门材料标签（或推荐搜索词） | 页面首次加载，无搜索条件 |
| 空结果 | 友好提示 + 推荐搜索词列表 | 查询返回0条 |
| 有结果 | 统计条 + 卡片列表 | 查询返回≥1条 |
| 加载中 | 骨架屏（最佳）或加载动画 | API请求进行中 |
| 错误态 | 错误提示 + 重试按钮 | API请求失败 |

## 5. 交互设计规范

### 5.1 搜索交互

| 交互 | 行为 |
|------|------|
| **输入搜索** | 用户输入时显示自动补全下拉（取API `/api/materials`，请求 ≥300ms debounce） |
| **输入变厚** | 材料输入框直接输入，不支持正则，纯模糊匹配 |
| **筛选联动** | 修改任意筛选条件不自动触发搜索，需点击"查询"按钮（避免现场误触频繁刷新） |
| **查询触发** | 点击"查询参数"按钮 或 Enter键发起查询 |
| **清除查询** | 一键重置所有条件，触发默认查询（显示所有参数） |

### 5.2 结果交互

| 交互 | 行为 |
|------|------|
| **卡片点击** | 点击卡片 → 展开/折叠辅助参数（手机端）；桌面端默认展开 |
| **分页** | 底部显示页码，点击加载下一页（不滚动加载，避免现场误触） |
| **排序** | ⏳ P2 待实现：支持按功率/厚度/质量等级排序 |
| **收藏** | ⏳ P3 待实现：收藏的卡片在顶部置顶 |

### 5.3 反馈交互

| 状态 | 反馈 | 时长 |
|------|------|------|
| 搜索中 | 搜索按钮变为加载状态 + 卡片区显示骨架屏 | 直至响应返回 |
| 成功 | 卡片淡入动画（200ms ease） | — |
| 空结果 | 显示空状态插画 + 推荐搜索词 | — |
| 失败 | 错误提示 + 重试按钮 | 3s 或用户点击重试 |
| 网络重连 | ⏳ P3 待实现：自动重试（指数退避） | 最多3次 |

## 7. 响应式布局规则

### 7.1 断点

| 断点 | 宽度 | 布局 | 列数 | 折叠行为 |
|------|------|------|------|----------|
| 手机 | < 600px | 单列 | 1列 | 辅助参数默认折叠 |
| 平板 | 600~1024px | 自适应 | 2~3列网格 | 辅助参数默认展开 |
| 桌面 | > 1024px | 宽屏 | 3~4列网格 | 辅助参数默认展开 |

### 7.2 自适应规则

```
搜索面板:     手机(纵向堆叠) → 桌面(横向排列)
结果卡片:     手机(单列全宽) → 平板(2列) → 桌面(3~4列)
辅助参数:     手机(默认折叠, tap展开) → 桌面(默认可见)
分页控制:     手机(小号数字) → 桌面(完整控件含跳转)
头部:         手机(紧凑56px) → 桌面(可略高64px)
```

### 7.3 触摸友好

- 所有可点击元素最小触摸目标 ≥ **44px × 44px**
- 按钮间距 ≥ **8px**，防止误触
- 下拉菜单展开层级 ≤ **2级**
- 避免hover-only的交互（手机没有hover）

## 9. 当前UI评审与优化方向

### 9.1 现有UI问题诊断（V1.0 Demo）

| 问题 | 严重度 | 描述 |
|------|--------|------|
| 核心参数展示不突出 | 🔴 严重 | 功率/速度/厚度 用跟辅助参数相同的字号和布局，现场操作员一眼看不到关键数据 |
| 辅助参数过载 | 🔴 严重 | 手机端 2列显示6个参数，每条卡片信息密度太高，阅读困难 |
| 缺少搜索补全 | 🟡 中等 | 只能手动输入材料名，新手不知道有哪些材料可搜，需加自动补全 |
| 缺少质量等级视觉标识 | 🟡 中等 | Ⅰ/Ⅱ/Ⅲ级只显示文字，没有颜色区分，用户不能快速筛选高质量参数 |
| 缺少热门推荐 | 🟢 轻微 | 初始状态没有推荐搜索词，新手不知道从何开始 |
| 缺少结果排序 | 🟢 轻微 | 按功率升序固定，用户不能按厚度/质量排序 |
| 加载反馈弱 | 🟢 轻微 | 只有文字"查询中..."，没有骨架屏或进度指示 |
| 桌面端未充分利用 | 🟢 轻微 | 桌面端跟手机端一样的单列布局，宽屏空间浪费 |

### 9.2 分阶段优化计划

#### 阶段一（V1.1）— 快速优化，不改前端结构

| 优化项 | 改动量 | 预期效果 |
|--------|--------|----------|
| 核心参数放大加粗，辅助参数缩小 | 仅CSS调整 | 现场操作员一眼看到功率/速度 |
| 手机端辅助参数默认折叠，tap展开 | JS新增折叠逻辑 | 卡片信息密度降低50% |
| 搜索输入框加placeholder推荐词 | 仅HTML | 降低新手使用门槛 |
| 质量等级颜色标识 | CSS新增色值 | Ⅰ/Ⅱ/Ⅲ级一目了然 |
| 空结果推荐搜索词 | HTML+JS | 无结果时引导用户 |

#### 阶段二（V1.2）— 交互升级

| 优化项 | 改动量 | 预期效果 |
|--------|--------|----------|
| 材料自动补全下拉 | 新增UI组件+API | 搜索效率提升50% |
| 桌面端网格布局 | CSS media query重构 | 桌面屏充分利用 |
| 加载骨架屏 | 新增UI组件 | 感知速度提升 |
| 搜索按钮加载态 | CSS动画 | 明确的操作反馈 |

#### 阶段三（V1.3）— 功能增强

| 优化项 | 改动量 | 预期效果 |
|--------|--------|----------|
| 热门材料标签（快捷点击） | 新增UI组件 | 新手快速上手 |
| 排序功能 | 新增UI+API | 灵活查看数据 |
| 参数展开/折叠记忆 | localStorage | 保持用户偏好 |
